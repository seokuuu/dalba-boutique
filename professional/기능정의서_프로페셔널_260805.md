## **1. 개요**

- 기존 dalba.co.kr(고도몰/NHN커머스5) 내부에 프로페셔널 라인을 추가하는 작업이다.
- 별도 도메인이나 폐쇄몰이 아니며, 시그니처 라인과 동일하게 GNB 탭으로 진입한다. 진입 시 `main/html.php?htmid=professional/*.html` 스킨으로 연결된다.
- 회원, 상품, 주문은 기존 몰과 완전히 공유하며 하나의 계정으로 양쪽 로그인이 가능하다.

## **3. 회원 및 인증 구조**

접근과 가격 제어의 기준은 회원등급('프로페셔널')이다. 개인/사업자 회원구분 필드는 사용하지 않는다.

### **3-1. 전체 흐름**

1. 회원가입은 기존 달바 일반 회원가입으로 통합한다. 별도의 프로 가입 절차는 없으며 누구나 일반회원으로 가입한다.
2. 로그인 후 PRO 랜딩에서 인증을 신청한다. 사업자등록증 또는 디자이너 자격증을 업로드하면 인증 게시판(proapply)에 등록된다.
3. 관리자가 서류를 확인하고 승인하면 해당 회원에게 '프로페셔널' 회원등급을 부여한다.
4. 등급 부여 후 프로페셔널 전용가(제휴가)와 전용 상품이 노출된다.

### **3-2. 로그인 및 등급 상태별 화면 분기 (PRO 랜딩)**

| **상태** | **노출** | **이동** |
| --- | --- | --- |
| 비로그인 | 로그인, 달바 통합 회원가입 버튼 | 로그인 후 PRO 랜딩으로 복귀하여 등급 재판별 |
| 로그인, 프로 미인증 | 인증 신청 버튼 | 인증 신청 페이지(선택, 강제 아님) |
| 로그인, 프로 인증 완료 | 별도 안내 없음 | 프로페셔널 메인 자동 진입 |

### **3-3. 접근 정책**

- 프로페셔널 페이지(메인, 스토어, 아티클, 프로덕트)는 모두 공개이며 일반 회원과 단순 탐색 고객도 자유롭게 열람할 수 있다.
- 차등은 상품 노출과 가격(등급별 제휴가, 회원전용가)에서만 발생한다. 페이지는 노출하되 구매와 가격만 등급으로 제한하는 구조이다.
- 인증 신청은 필수 진입 절차가 아니다. 신청 폼만 로그인을 요구하며, 열람 후 이탈이 자유롭다.

## **4. 사업자 및 디자이너 진위/중복 검증**

인증 신청 시 입력한 사업자등록번호를 자동으로 검증한다.

- 진위확인: 국세청 사업자등록 상태조회 API로 계속/휴업/폐업/미등록 상태를 판별한다.
- 중복확인: 고도몰 Open API(Board_List)로 인증 게시판(proapply)에 동일 사업자번호의 기신청 여부를 확인한다.
- 신규 Front 컨트롤러(ProVerifyController) 한 개가 두 검증을 수행하여 JSON으로 응답하며, 로그인 회원만 호출할 수 있다.
- 접근 URL: https://www.dalba.co.kr/professional/pro_verify.php

## **6. 게시판 구성**

프로페셔널 라인은 아래 게시판을 사용한다. 모두 고도몰 게시판 기본 기능이며 별도 DB 테이블을 생성하지 않는다. (이용약관과 개인정보 수집·이용 동의는 고도몰 기존 약관을 그대로 사용한다.)

| **게시판** | **ID** | **용도** | **주요 설정** | **연동 화면** |
| --- | --- | --- | --- | --- |
| 프로페셔널 회원신청 | proapply | 사업자/디자이너 인증 신청 접수 | 1:1문의형, 전건 비밀글, 파일첨부, 말머리(사업자/디자이너), 자동등록방지 해제 | verify.html |
| 아티클 | article | 뉴스/이벤트/컬래버 콘텐츠 | 게시형, 말머리(NEWS/EVENT/COLLABORATION), 대표이미지 | articles.html |
| 살롱(매장) | salon | 제휴 매장 정보 | 갤러리형, 관리자 전용 쓰기, 에디터 미사용(본문 평문 라벨), 말머리(지역) | store.html |
| 거래동의 약관 | salonterms | 살롱·헤어디자이너 거래동의 약관 본문 | 게시형, 관리자 등록, 최신 등록 글 노출 | verify.html 전체보기(terms_deal.html) |

- proapply: 인증 신청 시 서류(사업자등록증, 디자이너 자격증)를 첨부하여 등록한다. 신규 신청이 등록되면 관리자에게 알림을 발송할 수 있으며, 관리자가 서류를 검토한 뒤 회원등급을 부여한다.
- article: 말머리로 카테고리를 구분하며, articles.js가 게시판 목록을 조회해 카드 형태로 렌더한다.
- salon: 매장 1건이 게시글 1건에 대응한다. 매장명은 제목, 지역은 말머리, 사진은 대표이미지, 주소/전화/영업시간/좌표는 본문에 평문 라벨로 기입한다. store.js가 게시판 목록을 조회해 매장 리스트를 렌더하고, 지도는 본문의 주소를 지오코딩하여 마커로 표시한다.
- 거래동의 약관: 아티클과 동일하게 게시판으로 관리한다. 관리자가 약관을 게시글로 등록하며, 전체보기(terms_deal.html)가 해당 게시판의 최신 등록 글을 조회해 표시한다. 이용약관과 개인정보 수집·이용 동의는 고도몰 기존 약관을 그대로 사용한다.

## **7. 데이터베이스 영향**

신규 테이블과 컬럼이 없으며 공통 모듈을 수정하지 않는다. 스키마 변경이 없다.

- 인증 신청 데이터는 고도몰 게시판(proapply) 기본 기능을 사용한다. 별도 테이블을 생성하지 않는다.
- 등급 부여는 고도몰 회원등급 기본 기능을 사용한다.
- 진위 및 중복 검증은 외부 API 조회(국세청, 고도몰 Open API)로 처리하며 DB를 사용하지 않는다.

## **9. 관리자 설정 항목**

- 프로페셔널 회원등급 신설 및 승인 시 수동 등급 부여 프로세스
- 등급별 제휴가(전용가)와 상품 노출 설정
- 인증 승인 및 등급 변경 시 SMS 또는 카카오 알림톡 자동 발송(발신번호 등록, 템플릿 승인 전제)
- 게시판 생성 및 설정: 6장에 정의된 게시판(proapply, article, salon, salonterms)을 신설하고 각 게시판의 권한, 말머리, 파일첨부, 자동등록방지 등을 설정
- 거래동의 약관: 거래동의 약관 게시판(salonterms)에 약관 본문을 게시글로 등록(수정 시 새 글 등록하면 최신 글이 노출됨)
- 신청 접수 시 관리자 알림: 게시판 생성 시 함께 제공되는 알림 설정을 통해, proapply에 신규 신청이 등록되면 관리자에게 알림을 발송할 수 있다. (별도 개발 없이 게시판 기본 알림 기능 사용)

## **10. 배포 및 운영 환경**

- 컨트롤러는 PHP 8.2 호환으로 작성한다. 표준 함수만 사용하고 deprecated 문법이 없으며 클래스 속성은 명시적으로 선언한다.
- 신규 컨트롤러 배포는 커스터마이징 SFTP로 /data/module(개발소스)에 업로드한 뒤 개발소스관리에서 운영소스로 적용한다. 또는 /module(운영소스)에 직접 업로드한다.
- 공통 모듈을 수정하지 않으므로 웹앤모바일 PHP 8.2 업그레이드와 충돌 요소가 없다. 업그레이드 완료 및 커스텀 소스 보존 여부 확인 후 배포한다.
