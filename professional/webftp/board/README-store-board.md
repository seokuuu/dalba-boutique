# 매장(Store) 게시판 — 관리자 설정 & 매장 등록 가이드

Store 페이지의 매장 리스트/지도는 **고도몰 게시판**에 등록한 글을 읽어온다.
운영팀은 게시판에 매장을 "글"로 등록하면 되고, 지도는 주소로 자동 표시된다.

---

## A. 매장 게시판 만들기 (최초 1회 · 관리자)

관리자 → **게시판 관리**(게시판·리뷰 메뉴) → **게시판 추가**

| 항목 | 설정값 | 비고 |
|---|---|---|
| PC/모바일 사용여부 | 사용 | |
| **유형** | **갤러리형** | 매장 사진(대표이미지) 노출 |
| **아이디** | 예: `salon` | ⚠️ 이게 `bdId` — store.html 에 넣어야 함 |
| 게시판명 | 매장 안내 | |
| 리스트/읽기권한 | 전체(회원+비회원) | 누구나 조회 |
| **쓰기권한** | **관리자 전용** | 운영팀만 등록 |
| **에디터 사용** | **사용안함** | 본문 평문 → 주소/전화 자동 인식이 안정적 |
| 대표 이미지 노출 | 사용 | 매장 사진 |
| **기본 게시글 양식** | 아래 템플릿 붙여넣기 | 운영팀이 일관되게 입력하도록 |
| 말머리 기능(선택) | 지역 등록(서울/경기/부산 등) | 지역 검색·표시용 |

**기본 게시글 양식(본문에 붙여넣기용):**
```
주소:
전화:
영업시간: 월-금 10:00-20:00;토 10:00-18:00;일 휴무
좌표:
```

저장 후 **아이디(bdId)** 를 확인 → 개발자에게 전달(또는 store.html include 에 기입).

---

## B. 연동 (최초 1회 · 개발자)

1. `board/_board_article_store.html` 를 WebFTP `data/skin/front/dalba_main/board/` 에 업로드
2. `professional/store.html` 의 include 에 bdId 기입:
   `{=includeWidget('board/_board_article_store.html', ['bdId'=>'salon', 'listCnt'=>100])}`
   (그리고 그 위 테스트 샘플 `<li>` 들은 삭제) → dalba_main/professional/ 에 업로드
3. `js/professional/store.js`, geocoder 포함된 store.html 업로드
4. 네이버 지도 콘솔에서 해당 `ncpKeyId` 에 **Geocoding API 사용 신청** 확인

---

## C. 매장 등록/수정 (매번 · 운영팀)

방법 ①: 관리자 → 게시판 관리 → (매장 게시판) **게시글 관리 → 글 등록**
방법 ②: 쇼핑몰에서 매장 게시판 진입 → 관리자 로그인 상태로 **글쓰기**

입력:
1. **제목** = 매장명 (예: `달바 프로페셔널 청담 살롱`)
2. **말머리** = 지역 (선택, 예: `서울`)
3. **대표이미지** = 매장 사진 첨부
4. **본문**(에디터 꺼진 평문):
   ```
   주소: 서울 강남구 청담동 512-8
   전화: 02-000-0000
   영업시간: 월-금 10:00-20:00;토 10:00-18:00;일 휴무
   좌표: 37.5173,127.0473
   ```
   - **주소는 필수** (지도가 이 주소로 위치를 찾음)
   - **영업시간**은 요일 세그먼트를 `;` 로 구분
   - **좌표는 선택** — 비워두면 주소로 자동 검색. 정확한 위치를 원하면 네이버지도에서 좌표를 찾아 `위도,경도` 로 기입
5. 저장

→ 저장 즉시 Store 페이지에 반영 (개발자 작업 불필요 = 자가관리).

---

## D. 확인
1. `https://dalba.co.kr/main/html.php?htmid=professional/store.html` 접속
2. 등록한 매장이 리스트에 보이고, 검색(매장명/지역)됨
3. "지도에서 보기" → 지도에 위치 마커 + 주소/전화/영업시간 표시

문제 시 F12 콘솔에서 `[professional/store]` 경고 확인(지오코딩 실패/상세 로드 실패 등).
